# Constantine Hub v0.1.4

- Reconcile repository version with the live Hub line at v0.1.4.
- Compact DPI-safe WinForms layout so the full Godot card fits without vertical scrolling at the normal window size.
- Keep the dense log font unchanged.
- Treat an absent Godot runtime session as idle/warning, not a fatal error.
- Add Normal/Verbose log display while preserving full diagnostics in Save Log.
- Add stable GitHub Release update checks with SHA-256 verification.
- Add a separate updater bootstrapper with backup, startup handshake and rollback.
- Extend CI to package Hub + updater, emit checksum assets, and publish stable/dev GitHub releases from main.

The first installation of v0.1.4 is still manual because v0.1.3 does not contain the updater client. From v0.1.4 onward, stable updates can be installed from inside the Hub.
